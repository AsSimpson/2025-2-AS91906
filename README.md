# Xupu Sun's AS91906 Math Game project

This program is design for students to pratise their math skills. It includes basic arithemics to Integration and Differetiation. The game borrowed ideas from Pokemon game.

## Requirements:
python
pygame>=2.0.0
Pillow>=8.0.0

build-in libraries:
tkinter, json, os, time, random, math, winsound, platform

## How to run to game:
Firstly, ensure all the assets are being downloaded, the libraries above are installed. Double click main.py to run it.
